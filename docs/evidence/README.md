# Evidencias de la auditoría

Esta carpeta contiene las evidencias verificables de las correcciones de la Semana 4.

Reglas para las evidencias:

- utilizar nombres descriptivos;
- mostrar el resultado de la corrección o de su prueba;
- emplear únicamente datos ficticios;
- no incluir contraseñas, tokens, credenciales ni datos personales reales.

Cada corrección incluye una explicación en Markdown y la salida relevante de sus pruebas en un archivo de texto. Las capturas de pantalla pueden agregarse como apoyo visual, pero las salidas reproducibles constituyen la evidencia principal.
